FIXTURE DEMO — not live shopping data.

This page uses committed sample records and does not fetch live retailer prices. Sample prices, merchants, availability, discounts and offers are not verified current marketplace information and must not be treated as a real-world purchase recommendation.

The packaged demo uses a simulated reference time, and it may correctly return No verified recommendation. Fixture merchant destinations are intentionally not clickable purchase links.

How it works

  1. Write a plain-language request with a budget and exact variant details.
  2. The deterministic engine checks the committed fixture records.
  3. Only exact variants with independent evidence can be ranked.
  4. Expand an Evidence Card to inspect cost, provenance and G1–G7 gates.

Honest limits

This prototype does not scrape retailers, verify current stock, convert currency, or claim market-wide coverage. A failed or stale observation never becomes a guessed recommendation.

There is no user authentication. The single-process rate limit is best-effort demo protection, not production abuse prevention.

Privacy and feedback

Run queries, decisions and audit metadata are stored in the configured SQLite database so replay and verification can work. Do not enter personal, payment or secret information.
